# "Active" means recently updated, not merely Open

EONET leaves many events Open indefinitely: in October 2026 the oldest Open event dates from 2002, and roughly 99% of the 7,000+ Open events are wildfires. If "near me" showed everything EONET calls Open, it would surface years-old noise. So we define an Active Event as Open *and* having a Geometry within the Activity Window (default 30 days, user-adjustable, capped at 365). EONET's Open/Closed flag is still stored as-is and is never overridden or inferred by us.
